# 星河 API 开放平台概述

> 本资料用于系统演示，产品、域名、参数和联系方式均为虚构内容。上线前请在管理台删除并导入真实部门资料。

星河 API 开放平台是一套面向企业应用开发者的统一 AI 能力接入平台。它把文本分类、信息抽取、语音转写和文档解析等能力封装为标准 HTTPS API，适合客服质检、内容治理、会议纪要和业务流程自动化。平台不直接存储客户的原始业务文件；任务结果默认保留 24 小时，之后自动清理。

平台核心能力包括：统一鉴权、同步与异步任务接口、调用量统计、失败重试、回调通知和按应用隔离的权限控制。单个应用可以申请多个能力，但生产环境权限需要单独审核。

# 接入前准备

在控制台创建应用后会获得 `app_id`、`api_key` 和 `api_secret`。`api_secret` 只在创建时展示一次，必须保存在服务端密钥管理系统中，禁止写入前端代码、移动端安装包或公开仓库。测试环境与生产环境使用不同凭据，不能混用。

所有请求使用 HTTPS。接口基础地址为演示域名 `https://api.example.invalid/v1`。客户端时钟与标准时间的偏差必须小于 300 秒，否则签名校验会失败。建议在服务器开启 NTP 时间同步。

# 鉴权与请求头

请求必须包含 `X-App-Id`、`X-Timestamp`、`X-Nonce` 和 `Authorization` 四个请求头。签名原文由 HTTP 方法、请求路径、时间戳、随机串和请求体 SHA-256 摘要按换行符拼接，再使用 `api_secret` 做 HMAC-SHA256，最终编码为十六进制小写字符串。

每个 `X-Nonce` 在五分钟内只能使用一次。重试请求必须生成新的随机串和签名。请求体应使用 UTF-8 编码，JSON 请求的 `Content-Type` 必须是 `application/json`。

# 文本分类接口

文本分类接口路径为 `POST /text/classify`。请求体包含 `text` 和 `labels`：`text` 长度为 1 至 8000 个 UTF-8 字符，`labels` 为 2 至 50 个候选标签。可选参数 `top_k` 默认为 1，取值范围 1 至候选标签数量。

成功响应包含 `request_id`、`results` 和 `usage`。`results` 按置信度降序排列，每项包含 `label` 和 `score`。线上排障时应记录 `request_id`，但不要在工单中粘贴未脱敏的原始文本。

# 文档解析异步接口

文档解析采用异步任务模式。先调用 `POST /document/tasks` 上传文件并获得 `task_id`，再调用 `GET /document/tasks/{task_id}` 查询状态。状态依次可能为 `queued`、`running`、`succeeded` 或 `failed`。查询间隔不得短于两秒，推荐使用指数退避。

单个文件最大 20 MB，支持 PDF、DOCX、PPTX、PNG 和 JPEG。扫描版 PDF 会自动 OCR，但低清晰度、旋转或严重阴影可能降低识别质量。任务成功后，结果下载地址有效期为 30 分钟。

# 回调通知

创建异步任务时可传入已在控制台登记的 `callback_url`。平台向该地址发送 POST 请求，并在 `X-Callback-Signature` 中附加签名。接收方必须先验签，再根据 `task_id` 幂等处理；同一事件可能重复投递，不能仅按到达次数记账。

回调端点应在五秒内返回 2xx。超时或非 2xx 会触发最多五次重试，间隔依次为 10 秒、30 秒、2 分钟、10 分钟和 30 分钟。内网地址、localhost 和未登记域名不能作为回调地址。

# 限流与重试

测试应用默认每分钟 60 次请求，生产应用的额度以控制台显示为准。超过额度返回 HTTP 429 和错误码 `RATE_LIMITED`，响应头 `Retry-After` 表示建议等待秒数。客户端应遵循该值并采用带随机抖动的指数退避，禁止无间隔循环重试。

HTTP 500、502、503、504 可对幂等请求重试，最多三次。创建任务等非幂等操作重试时必须使用唯一的 `Idempotency-Key`，有效期 24 小时。HTTP 400、401、403 一般不应自动重试，应先修正参数、凭据或权限。

# 常见错误：AUTH_001

HTTP 401、错误码 `AUTH_001` 表示签名无效。按顺序检查：一、`app_id` 是否属于当前环境；二、服务器时间误差是否超过 300 秒；三、签名原文中的请求路径是否包含查询串；四、JSON 请求体摘要是否基于实际发送的字节；五、HMAC 结果是否为十六进制小写。

如果仍无法解决，请记录请求时间、`request_id`、请求路径和已脱敏的请求头后提交工单。不得提交 `api_secret`、完整 Authorization 或原始业务数据。

# 常见错误：PERMISSION_DENIED

HTTP 403、错误码 `PERMISSION_DENIED` 表示应用没有目标能力或环境的访问权限。先在控制台的“应用—能力授权”查看能力状态；测试权限不代表已获得生产权限。新授权通常在一分钟内生效，期间可刷新应用配置但不要重新创建密钥。

# 常见错误：INVALID_ARGUMENT

HTTP 400、错误码 `INVALID_ARGUMENT` 表示请求参数不符合接口约束。响应中的 `details.field` 指向问题字段，`details.reason` 给出原因。重点检查必填字段、字符长度、枚举值、JSON 类型和 Content-Type。不要通过重复重试解决参数错误。

# 文档解析结果异常

文档出现漏字或阅读顺序错误时，先检查原文件是否为扫描件、分辨率是否低于 150 DPI、页面是否旋转以及是否存在多栏或复杂表格。建议将扫描件处理为 300 DPI、方向正确的 PDF 后重试。若只有个别页面异常，应记录页码和 `task_id`，提交脱敏样例给技术支持。

# 服务超时与连接失败

连接超时先检查客户端是否能解析平台域名、出口防火墙是否允许 443 端口、代理是否正确配置。读取超时建议设置为同步接口 30 秒、异步创建接口 60 秒；不要把长文档解析当作同步请求等待。平台返回 504 时可以按幂等规则最多重试三次。

# 技术支持升级

机器人没有可靠来源、检索置信度过低、同一错误按指南处理后仍复现，或问题涉及账号冻结、计费争议和生产事故时，应转人工技术支持。工单至少包含：环境、应用 ID（可提供，不能提供密钥）、发生时间、请求 ID 或任务 ID、错误码、复现步骤、已完成的排查、脱敏请求样例和业务影响。

P1 生产事故请走内部紧急值班通道；普通问题通过内部工单系统联系“星河平台技术支持”。技术支持不会索要 `api_secret`。
