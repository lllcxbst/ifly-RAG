## LightRAG

This project integrates **LightRAG 1.5.6** as an embedded knowledge-graph RAG engine.

- Project: https://github.com/HKUDS/LightRAG
- Package: `lightrag-hku==1.5.6`
- License: MIT
- Copyright: © 2025 LightRAG Team

LightRAG is used for entity/relation extraction, product-isolated graph storage,
incremental graph updates, graph traversal and structured retrieval results. The
application retains its own authentication, PostgreSQL document metadata,
pgvector semantic retrieval, source citation validation and refusal policy.

The full LightRAG MIT license is available in the upstream repository and in
the installed Python package metadata.
